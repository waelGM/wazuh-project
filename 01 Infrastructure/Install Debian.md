## Prerequisite

The virtual machine is created with the Debian ISO attached: [[Create a VMware Virtual Machine]].

## Installation

1. Start the virtual machine.
2. Select **Graphical install** in the boot menu.
3. Choose your language, location and keyboard layout.
4. Set a host name.
5. If you want to join the machine to a domain that you have, or use a specific domain, enter it here. It was left empty in this lab.
6. Set the root password.
7. Create a user account.
8. Set the password of the user account.
9. Choose the time zone you want.
10. Partition the disk. Choose **Guided - use entire disk**.
11. You can choose to install or not. It was not installed in this lab.
12. If you have a stable Internet connection, choose **Yes** to use a network mirror. This lets you install the latest software and avoids missing packages.
13. Select the software to install. Cinnamon is used in this lab instead of GNOME.
14. Finish the installation and restart the virtual machine.
15. Sign in with the account you created and its password.
