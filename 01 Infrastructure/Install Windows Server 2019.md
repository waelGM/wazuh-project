## Installation

1. Choose your time format, click **Next**, then click **Install now**.
2. Click **I don't have a product key**, unless you have one and want to use it.
3. Choose **Standard (Desktop Experience)**, with the graphical interface. If you choose the first option, the system has no graphical interface.

![[install-windows-server-2019--extra-03--edition-selection.png]]
*the edition list: Windows Server 2019 Standard, Standard (Desktop Experience), Datacenter, Datacenter (Desktop Experience); the installer is in French*
4. Choose **Custom**. As this is the first operating system on this VM, there is nothing to keep.
5. Create your password. Make sure it meets the complexity criteria (uppercase, lowercase, digit and so on). Click **Finish** and wait again.
